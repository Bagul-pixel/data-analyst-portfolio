# Отчёт о продажах

## Инструменты
* Power BI Desktop
* Power Query (очистка и трансформация данных)
* DAX (расчетные меры и таблицы)

## Как посмотреть отчет
* **Скачать интерактивный файл:** нажмите на файл `Отчёт о продажах.pbix` в списке выше и выберите *Download raw file*.
* **Посмотреть без установки ПО:** откройте файл `Отчёт о продажах.pdf` в этом репозитории.
